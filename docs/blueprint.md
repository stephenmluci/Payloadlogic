# **App Name**: Truckin' Smart Assist

## Core Features:

- Secure Authentication: User authentication and authorization to secure access to the app.
- Dashboard Overview: Dashboard displaying key metrics like total revenue, expenses, and net profit.
- Load Management: Manage loads by creating, updating, and tracking their status (pending, in-transit, delivered).
- Password Generation Tool: Use generative AI to generate custom, secure passwords upon initial registration or when resetting a user's password.
- Expense Tracking: Record and categorize expenses associated with loads, such as fuel, maintenance, and payroll.
- Client Management: Maintain a client list with contact information for easy load assignment and communication.
- System Settings: Configure default operational settings like payroll percentage and recurring expenses.

## Style Guidelines:

- Primary color: A calm and reliable blue (#4A6EBB) to convey trustworthiness.
- Background color: A very light grey (#F2F4F7), almost white, to give emphasis to the other colors and important on-screen information
- Accent color: A muted violet (#9352B3) for interactive elements and calls to action.
- Headline font: 'Space Grotesk', sans-serif, for headlines and titles to give a tech-focused, clean appearance; body font: 'Inter', sans-serif
- Code font: 'Source Code Pro' for displaying any code snippets, with a monospaced font for legibility
- Use a set of consistent, modern icons from a library like FontAwesome or Material Icons to represent different actions and data categories.
- Employ a grid-based layout to ensure consistent spacing and alignment across all pages.
